# Solmara

A music studio for your computer, in the making: instruments, effects and a
timeline to write, play, record and mix your music.

Solmara is in development, and there is no download yet. When there is, it
will be under [Releases](https://github.com/mattias800/solmara/releases).

- **Website:** https://mattias800.github.io/solmara/
- **Found a problem, or have an idea?** [Tell us here](https://github.com/mattias800/solmara/issues/new/choose).

This repository holds the website, the issue tracker and, in time, the
installers and the catalog of free sounds the app downloads. Solmara's own
source code is not published here.

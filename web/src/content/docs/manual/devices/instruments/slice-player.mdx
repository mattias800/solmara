**A design of Solmara's own.**

A loop cut into parts at its hits, each part on a key with its own pitch, level, pan, decay and reverse, named by what it sounds like; it writes a drum pattern that plays the loop, to remix it in the drum editor. A filter with an LFO, poly or choke voices, and a held tail for slower tempos.

[Slice Player on the website](/solmara/instruments/slice-player/)

## Appendix: every control

Each of the device's controls by the name automation and the inspector give it, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Level | 0% to 100% | 90% |
| Velocity | 0% to 100% | 30% |
| Pitch | -24 semitones to 24 semitones | 0 semitones |
| Voices | Poly, Choke | Choke |
| Gap | Decay, Stretch, Off | Decay |
| Filter | Low-pass, Band-pass, High-pass | Low-pass |
| Cutoff | 20 Hz to 20000 Hz | 20000 Hz |
| Resonance | 0% to 100% | 0% |
| Attack | 0 ms to 500 ms | 0 ms |
| Release | 1 ms to 2000 ms | 40 ms |
| LFO rate | 0.05 Hz to 20 Hz | 1 Hz |
| LFO to cutoff | 0% to 100% | 0% |

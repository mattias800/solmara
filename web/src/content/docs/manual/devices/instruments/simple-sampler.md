Plays one sample from a root note, with trim, forward looping and an ADSR amplitude envelope.

[Simple Sampler on the website](/solmara/instruments/simple-sampler/)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Root note | 0 MIDI note to 127 MIDI note | 60 MIDI note |
| Level | 0 linear to 1 linear | 1 linear |
| Playback | Gate, One shot | Gate |
| Interpolation | Linear, Cubic, Sinc | Cubic |
| Sample start | 0% to 100% | 0% |
| Sample end | 0% to 100% | 100% |
| Loop start | 0% to 100% | 0% |
| Loop end | 0% to 100% | 100% |
| Loop | Off, Forward | Off |
| Attack | 0 ms to 20000 ms | 0 ms |
| Decay | 0 ms to 20000 ms | 0 ms |
| Sustain | 0 linear to 1 linear | 1 linear |
| Release | 0 ms to 20000 ms | 8 ms |

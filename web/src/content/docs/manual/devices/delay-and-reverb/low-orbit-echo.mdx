**An emulation of an analog original,** modeled on the 1970s Japanese tape echo with three playback heads and a spring reverb.

A modeled tape echo: a loop of tape that never stops, one record head, and three playback heads at fixed distances along it, with a spring reverb beside it. A twelve-position selector chooses which heads play and whether the springs do. The repeat rate is the motor's speed, so turning it bends the pitch of every echo still on the tape, and it can be set from the project's tempo instead. Intensity feeds the heads back to the record head: each pass is recorded again, so repeats darken and compress, and past about 70 with one head they grow until the tape saturates and the machine sings by itself; more heads sing sooner, all three by about 53. Bass and treble on the echoes, echo and reverb volume, input level, wow, flutter, hiss, and the dry signal passed beside it with no delay. The tape is the tape machine's model of hysteresis. Modeled on the Japanese tape echo of the middle 1970s with three heads and a spring tank, the echo of dub and of space rock.

| Sync | Off, On | Off |
| Division | 13 choices: 1/32, 1/16T, 1/16, 1/8T, … | 1/8 |
| Intensity | 0 to 100 | 30 |
| Bass | 0 to 100 | 50 |
| Treble | 0 to 100 | 50 |
| Echo volume | 0 to 100 | 50 |

| Input | 0 to 100 | 50 |
| Dry | 0% to 100% | 100% |

| Hiss | 0 to 100 | 0 |
| Output | -24 dB to 12 dB | 0 dB |

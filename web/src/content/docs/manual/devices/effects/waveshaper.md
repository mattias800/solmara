**A design of Solmara's own.**

Bends the audio through a curve, tanh, a folder, a sine, an asymmetric one, or hard, met off its middle by the bias, at twice the rate.

[Waveshaper on the website](/solmara/effects/#waveshaper)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Drive | 0 dB to 36 dB | 6 dB |
| Curve | Tanh, Fold, Sine, Asymmetric, Hard | Tanh |
| Bias | -1 linear to 1 linear | 0 linear |
| Mix | 0 linear to 1 linear | 1 linear |
| Output | -24 dB to 24 dB | 0 dB |

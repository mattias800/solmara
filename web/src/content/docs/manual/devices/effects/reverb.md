**A design of Solmara's own.**

A space to ring in: room, hall, plate, or a shimmer whose tail climbs in pitch, with pre-delay, damping, a size to sweep, a freeze, and ducking, by its own input or by a sidechain.

[Reverb on the website](/solmara/effects/#reverb)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Model | Room, Hall, Plate, Shimmer | Hall |
| Decay | 0.2 s to 20 s | 2.5 s |
| Size | 0 linear to 1 linear | 0.5 linear |
| Pre-delay | 0 ms to 250 ms | 20 ms |
| Damping | 500 Hz to 20000 Hz | 6000 Hz |
| Low cut | 20 Hz to 1000 Hz | 100 Hz |
| Diffusion | 0 linear to 1 linear | 0.7 linear |
| Modulation | 0 linear to 1 linear | 0.3 linear |
| Shimmer | 0 linear to 1 linear | 0.5 linear |
| Interval | Octave up, Fifth up, Octave down | Octave up |
| Width | 0 linear to 1 linear | 1 linear |
| Duck | 0 linear to 1 linear | 0 linear |
| Mix | 0 linear to 1 linear | 0.25 linear |
| Freeze | Off, On | Off |

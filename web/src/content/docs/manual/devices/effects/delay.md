**A design of Solmara's own.**

Repeats in time with the project or free: clean, tape, lo-fi, diffuse, or reversed, with filters, wobble, ping pong, and ducking, by its own input or by a sidechain.

[Delay on the website](/solmara/effects/#delay)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Mode | Clean, Tape, Lo-fi, Diffuse, Reverse | Clean |
| Sync | Off, On | On |
| Division | 13 choices: 1/32, 1/16T, 1/16, 1/8T, … | 1/8. |
| Time | 1 ms to 2000 ms | 250 ms |
| Feedback | 0 linear to 1.2 linear | 0.45 linear |
| Low cut | 20 Hz to 2000 Hz | 80 Hz |
| High cut | 500 Hz to 20000 Hz | 8000 Hz |
| Mod rate | 0.05 Hz to 10 Hz | 0.5 Hz |
| Mod depth | 0 linear to 1 linear | 0 linear |
| Character | 0 linear to 1 linear | 0.5 linear |
| Spread | 0 linear to 1 linear | 0 linear |
| Duck | 0 linear to 1 linear | 0 linear |
| Ping pong | Off, On | Off |
| Mix | 0 linear to 1 linear | 0.3 linear |
| Freeze | Off, On | Off |

**A design of Solmara's own.**

Takes fewer samples a second and keeps each to fewer bits: grit and alias of early samplers.

[Bitcrusher on the website](/solmara/effects/#bitcrusher)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Bits | 1 bits to 16 bits | 8 bits |
| Rate | 100 Hz to 48000 Hz | 48000 Hz |
| Mix | 0 linear to 1 linear | 1 linear |
| Output | -24 dB to 24 dB | 0 dB |

**A design of Solmara's own.**

A stereo imager for the master and for buses, the mastering family's: how wide each of four bands is, from mono through as it came to its side doubled, split where the crossover splits so at every width 1 it changes nothing; and the lows folded to mono below a frequency, as a master's should be.

[Trollspegeln Imager on the website](/solmara/effects/#trollspegeln-imager)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Low split | 20 Hz to 1000 Hz | 200 Hz |
| Middle split | 200 Hz to 8000 Hz | 2000 Hz |
| High split | 1000 Hz to 16000 Hz | 8000 Hz |
| Low width | 0 linear to 2 linear | 1 linear |
| Low mid width | 0 linear to 2 linear | 1 linear |
| High mid width | 0 linear to 2 linear | 1 linear |
| High width | 0 linear to 2 linear | 1 linear |
| Mono below | Off, On | On |
| Mono below | 20 Hz to 500 Hz | 120 Hz |
| Output | -24 dB to 24 dB | 0 dB |

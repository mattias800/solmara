Evens out level: turns down what rises above a threshold, by a ratio. It can listen to another track by sidechain, through a filter, so a kick ducks a bass.

[Compressor on the website](/solmara/effects/#compressor)

## Controls

Each of the device's controls, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Threshold | -60 dB to 0 dB | -18 dB |
| Ratio | 1 to 20 | 4 |
| Attack | 0.1 ms to 200 ms | 10 ms |
| Release | 5 ms to 2000 ms | 100 ms |
| Knee | 0 dB to 24 dB | 6 dB |
| Makeup | -12 dB to 24 dB | 0 dB |
| Mix | 0 linear to 1 linear | 1 linear |
| SC low cut | 20 Hz to 2000 Hz | 20 Hz |
| SC high cut | 100 Hz to 20000 Hz | 20000 Hz |
| Lookahead | 0 ms to 20 ms | 0 ms |
| SC listen | Off, On | Off |

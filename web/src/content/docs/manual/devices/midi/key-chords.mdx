A MIDI device: keeps each note to a key and scale, moving one outside it to the nearest scale note or silencing it, and can play each as a chord of the scale, of one to five notes stacked in its thirds, inverted or opened, with an octave above or below and a colour on top.

[Key Chords on the website](/solmara/write/#key-chords)

## Appendix: the factory presets

Key Chords comes with 8 factory presets. Click the device's name to browse them, each with a line on what it is, and try one while the song plays. See [presets](/solmara/manual/guides/devices/#presets).

A Minor Ninths, C Major Open, D Dorian Nights, D Pentatonic Melody, E Harmonic Minor, F Lydian Light, G Dominant Colours, Whole Tone Glass.

## Appendix: every control

Each of the device's controls by the name automation and the inspector give it, with the values it can take and the one it starts at.

| Control | Range | Starts at |
| --- | --- | --- |
| Key | 12 choices: C, C#, D, D#, … | C |
| Scale | 15 choices: Project, Major, Minor, Lydian, … | Major |
| Filter notes | Off, On | Off |
| Chords | Off, On | On |
| Notes | 1 to 5 | 3 |
| Inversion | 0 to 4 | 0 |
| Open chords | Off, On | Off |
| Add octave up | Off, On | Off |
| Add octave down | Off, On | Off |
| Add color | Off, On | Off |
| Alter | Off, On | Off |

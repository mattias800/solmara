---
title: Keyboard shortcuts
description: Every key in Solmara, by where it works.
---

On a Mac, <kbd>Cmd</kbd> is Command and <kbd>Alt</kbd> is Option. On Windows and Linux, <kbd>Cmd</kbd> is <kbd>Ctrl</kbd>, and Delete is <kbd>Delete</kbd> where a Mac has <kbd>Backspace</kbd>. Menus name their keys, and the help line names the keys of whatever is under the mouse.

## Everywhere

| Key | Does |
| --- | --- |
| <kbd>Space</kbd> | Play or stop |
| <kbd>F9</kbd> | Record |
| <kbd>Cmd</kbd>+<kbd>Z</kbd> / <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo |
| <kbd>Cmd</kbd>+<kbd>S</kbd> | Save |
| <kbd>Cmd</kbd>+<kbd>,</kbd> | Preferences |
| <kbd>Esc</kbd> | Take back a drag while the mouse is still down; close a menu or a picker |
| <kbd>Caps Lock</kbd> | Play notes from the computer keyboard, on or off |
| <kbd>?</kbd> | Hide or show the help line |

## Panels and views

| Key | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | Show or hide the library |
| <kbd>Cmd</kbd>+<kbd>Alt</kbd>+<kbd>I</kbd> | Show or hide the inspector |
| <kbd>Cmd</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd> | Show or hide the devices |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>, or the key left of <kbd>1</kbd> | Show or hide the mixer |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | The editors you have open, the latest first |
| <kbd>Enter</kbd> / <kbd>Esc</kbd> | Open the selected clip's editor / go back to the arrangement |
| <kbd>Cmd</kbd>+<kbd>+</kbd>, <kbd>Cmd</kbd>+<kbd>-</kbd>, <kbd>Cmd</kbd>+<kbd>0</kbd> | Zoom the arrangement in, out, to 100 % |
| <kbd>Cmd</kbd> + scroll wheel | Zoom where the mouse is |

## Tracks

| Key | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | New MIDI track |
| <kbd>Cmd</kbd>+<kbd>T</kbd> | New audio track |
| <kbd>Cmd</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> | New return track |
| <kbd>Up</kbd> / <kbd>Down</kbd> | The track above or below; with <kbd>Shift</kbd>, add it to the selection |
| <kbd>Cmd</kbd>+<kbd>R</kbd> or <kbd>F2</kbd> | Rename |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Cmd</kbd>+<kbd>G</kbd> | Group the selected tracks |
| Delete | Delete the selected tracks |

## Clips

| Key | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>C</kbd>, <kbd>X</kbd>, <kbd>V</kbd> | Copy, cut, paste (at the playhead, on the selected track) |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Duplicate after itself |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | Split at the playhead |
| <kbd>0</kbd> | Mute or unmute |
| <kbd>Cmd</kbd>+<kbd>R</kbd> or <kbd>F2</kbd> | Rename |
| Arrows | Move a grid step, or to the track above or below |
| <kbd>Shift</kbd>+<kbd>Left</kbd> / <kbd>Right</kbd> | A grid step shorter or longer |
| <kbd>Alt</kbd>+arrows | Move the focus to the next clip that way |
| <kbd>Cmd</kbd>+<kbd>A</kbd> | Select all |
| Delete | Delete |

## The grid

These work on the grid of the editor you clicked last, the arrangement's or the piano roll's.

| Key | Does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>1</kbd> / <kbd>2</kbd> | A finer / a coarser grid |
| <kbd>Cmd</kbd>+<kbd>3</kbd> | Triplets on or off |
| <kbd>Cmd</kbd>+<kbd>4</kbd> | Snapping on or off |
| <kbd>Cmd</kbd>+<kbd>5</kbd> | A fixed grid or the adaptive one |
| <kbd>Cmd</kbd> while dragging | Off the grid, to the tick |
| <kbd>Alt</kbd> while dragging | Copy instead of move |

## Notes

| Key | Does |
| --- | --- |
| Arrows | Move a grid step or a semitone |
| <kbd>Shift</kbd>+<kbd>Up</kbd> / <kbd>Down</kbd> | Move an octave |
| <kbd>Shift</kbd>+<kbd>Left</kbd> / <kbd>Right</kbd> | A grid step shorter or longer |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | The next / the previous note in time |
| <kbd>Cmd</kbd>+<kbd>U</kbd> | Quantize |
| <kbd>Cmd</kbd>+<kbd>C</kbd>, <kbd>X</kbd>, <kbd>V</kbd>, <kbd>D</kbd>, <kbd>A</kbd> | Copy, cut, paste, duplicate, select all |
| <kbd>Cmd</kbd>+<kbd>K</kbd> | Composer: Notes or Chords |
| <kbd>Cmd</kbd>+<kbd>W</kbd> | Close a Composer window |

## The computer keyboard as a piano

With <kbd>Caps Lock</kbd> on:

| Key | Plays |
| --- | --- |
| <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> <kbd>F</kbd> <kbd>G</kbd> <kbd>H</kbd> <kbd>J</kbd> <kbd>K</kbd> | The white keys from C |
| <kbd>W</kbd> <kbd>E</kbd> <kbd>T</kbd> <kbd>Y</kbd> <kbd>U</kbd> | The black keys |
| <kbd>O</kbd> <kbd>L</kbd> <kbd>P</kbd> | On up |
| <kbd>Z</kbd> / <kbd>X</kbd> | An octave down / up |
| <kbd>C</kbd> / <kbd>V</kbd> | Softer / louder |

## Devices

| Key | Does |
| --- | --- |
| Delete | Remove the selected device |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Duplicate it |
| <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | Open Vintergatan's window |
| <kbd>Shift</kbd> while turning a knob | Fine steps |

---
title: 'Arrangement: mouse and keys'
description: Every mouse gesture and key on the arrangement's clips and automation lanes.
---

On a Mac, <kbd>Cmd</kbd> is the Command key and <kbd>Alt</kbd> is Option. On Windows and Linux, <kbd>Cmd</kbd> is <kbd>Ctrl</kbd>.

## Clips

| Gesture | On | What it does |
| --- | --- | --- |
| Double-click, hold and drag | An empty place on a track | Draws a new clip as long as the drag |
| Double-click | An empty place on a track | Makes a clip as long as the last one drawn, or one grid cell |
| Right-click | An empty place on a track | Creates any kind of clip the track plays, adds a track, pastes, moves the playhead |
| Click | A clip's name strip | Selects it, and plays the song from its start |
| Click | A clip's body | Selects it, and puts the playhead there |
| <kbd>Shift</kbd>- or <kbd>Cmd</kbd>-click | A clip | Adds it to the selection, or takes it out |
| Drag a box | Empty space | Selects every clip it touches |
| Drag | A clip | Moves it, and every selected clip with it |
| <kbd>Alt</kbd>-drag | A clip | Copies it |
| <kbd>Cmd</kbd> while dragging | A clip | Leaves the grid |
| <kbd>Shift</kbd>+<kbd>Cmd</kbd>-drag | A clip's body | Slips its content under it, leaving the clip in place |
| Drag | Upper half of the right edge | Makes the clip longer or shorter. Stops a loop |
| Drag | Lower half of the right edge | Loops a MIDI or automation clip |
| Drag | The left edge | Trims the clip's start |
| Double-click | A MIDI clip | Opens it in its Composer window |
| Right-click | A clip | The clip's menu: rename, mute, loop, colour, split, and more |

## Clip keys

| Key | What it does |
| --- | --- |
| <kbd>Cmd</kbd>+<kbd>A</kbd> | Selects every clip |
| <kbd>Cmd</kbd>+<kbd>D</kbd> | Duplicates the selected clips, straight after them |
| <kbd>Cmd</kbd>+<kbd>X</kbd>, <kbd>C</kbd>, <kbd>V</kbd> | Cuts, copies and pastes clips. A paste lands at the playhead, on the selected track |
| <kbd>Cmd</kbd>+<kbd>E</kbd> | Splits the selected clip at the playhead |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Deletes the selected clips |
| <kbd>Enter</kbd> | Opens the selected clip's editor in the main area |
| <kbd>Esc</kbd> | Goes back from a clip's editor to the arrangement |

## Automation lanes

| Gesture | On | What it does |
| --- | --- | --- |
| Double-click, hold and drag | An empty stretch of a lane | Draws a new automation clip as long as the drag |
| Double-click | An empty stretch of a lane | Makes a clip as long as the last one drawn |
| Double-click | A clip's curve | Adds a point |
| Double-click | A point | Removes it |
| Drag | A point | Moves it, and every selected point with it |
| <kbd>Alt</kbd>-drag | The line between two points | Bends it |
| <kbd>Cmd</kbd>-drag | A clip's curve | Draws the curve freehand |
| <kbd>Shift</kbd>-drag | A clip's curve | Draws a straight line |
| Drag a box | Away from the points | Selects the points inside |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Selected points | Deletes them |
| Right-click | A point | Chooses a line, a hold or a bend to the next point |
| Drag | A clip's name strip | Moves the clip |
| Drag | Bottom edge of the lane's head | Makes the lane taller or shorter |
| Double-click | Bottom edge of the lane's head | Brings the lane back to its usual height |
